## What it does

<CardGrid>
  <Card title="One governed endpoint" icon="approve-check">
    Every request is authenticated, checked against a budget, sent to a model
    you chose, and recorded.
  </Card>
  <Card title="Cost you can trust" icon="seti:money">
    Input, output, cache read and cache write are priced separately, per model
    and per region. A coding agent is mostly cache reads: price them as input
    and the bill is overstated several-fold.
  </Card>
  <Card title="Cost per branch, ticket and PR" icon="git-pull-request">
    Read out of the request as it passes, then confirmed against GitHub
    (experimental).
    "PAY-1183 cost $18.40, merged."
  </Card>
  <Card title="Budgets that hold" icon="warning">
    Per person, per team, per deployment. A soft limit warns and closes the
    routes you marked as too expensive to keep serving. A hard limit stops the
    request and says when the budget resets.
  </Card>
</CardGrid>

## Three things it will never do

1. **Store a prompt or a response.** Bodies are pattern-matched in flight and
   discarded.
2. **Show one engineer another engineer's numbers.**
3. **Hide what it could not attribute.** Unattributed spend appears beside
   every attributed number.

[What each of those means in practice](/docs/start/what-it-is/#three-things-it-will-never-do).
